# lorem-jeongeum

## 소개

'lorem-ipsum' 패키지를 보고, 한국어로도 저런 게 있으면 좋지 않을까? 라는 생각에서 시작되어 만들고 있는 글자 생성 라이브러리입니다.  
영명, 한글명 메소드를 통해서 글자, 문장, 문단 생성을 할 수 있으며, 옛한글로도 글자, 문장, 문단을 생성할 수 있습니다.
